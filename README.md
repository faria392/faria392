## 🚀 Projetos em destaque

### 🏆 3rd WEAR Dataset Challenge @ HASCA 2026 — 17º lugar
Competição internacional de **reconhecimento de atividades humanas** (19 classes) com dados multimodais: sensores inerciais vestíveis e features de vídeo egocêntrico.

- Baselines por modalidade (IMU e vídeo), **late fusion** e **stacking**
- Validação com **GroupKFold por participante** para evitar vazamento de dados
- Experimentos controlados: uma variável por vez, com baseline congelado
- **Resultado:** 17º lugar no leaderboard (score 0,855)

`Python` `Scikit-learn` `NumPy` `Pandas` `Google Colab`

### 🤖 [Agente de RH com IA Generativa](https://github.com/faria392/agente-rh)
Assistente conversacional que responde dúvidas de RH com base em documentos internos, usando **RAG (Retrieval-Augmented Generation)**.

- Carregamento e divisão de documentos, geração de embeddings e busca vetorial
- Respostas contextualizadas geradas por LLM a partir dos trechos recuperados

`Python` `LangChain` `LLMs` `Embeddings` `Banco vetorial`
